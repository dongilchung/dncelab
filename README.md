# DNCE Lab GitHub Pages site

Built as a Jekyll site so News, People, and Publications can be edited as individual Markdown files in GitHub.

## Publish
Create a public repository, upload this folder to the repository root, then Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Edit
- News: `_posts/`
- People: `_people/`
- Publications: `_publications/`
- General pages: `research.md`, `links.md`, `join.md`, `contact.md`
- Design: `assets/css/style.css`
